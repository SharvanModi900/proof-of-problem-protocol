| Layer | Name                             | Function                                                                                               |
| ----- | -------------------------------- | ------------------------------------------------------------------------------------------------------ |
| L0    | **Local Proof Submission**       | Individuals submit real-world problems they face.                                                      |
| L1    | **Validation Layer**             | Community-based verification (via votes, peer review, evidence).                                       |
| L2    | **Tokenization Layer**           | Problems are minted into NFTs or SBTs to represent proof of existence and priority.                    |
| L3    | **Funding / Collaboration**      | Ethical investors, developers, or institutions view validated problems to co-create or fund solutions. |
| L4    | **Problem-Solution Matchmaking** | Platforms and tools enable pairing of validated problems with verified solvers.                        |
