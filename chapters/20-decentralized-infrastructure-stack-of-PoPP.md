# 📘 Chapter 20: The Decentralized Infrastructure Stack of PoPP

## 🏗️ Why Infrastructure Independence Matters

A truth protocol cannot be built on rented trust.  
If PoPP relied on AWS, Google Cloud, or any single host—  
then truth would still be hostage to outages, censorship, or politics.

That’s why **PoPP** is powered by a **fully decentralized technology stack**—designed to survive planetary collapse or political rejection.

---

## 🧱 The PoPP Tech Stack (Layer-by-Layer)

### 1. Data Storage Layer: IPFS / Filecoin / Arweave

| Component | Role |
|-----------|------|
| 🧾 IPFS    | Decentralized, content-addressed storage of ticket metadata, proofs, images |
| 💾 Filecoin | Incentivized long-term storage of full-resolution evidence & validator reports |
| 🔁 Arweave | Permanent “Memory Chain” archive for resolved ticket history |

**Result:** Immutable + censorship-resistant public problem archive

---

### 2. Blockchain Layer: Cosmos SDK / Substrate / Solana

| Component     | Role |
|---------------|------|
| 🧬 Cosmos SDK  | Modular PoPP chain with fast finality and sovereignty |
| 🔄 IBC         | Cross-chain ticket verification & data sharing |
| ⚡ Solana Adapter | Optional L2 module for high-speed micro-validations |

**Result:** Scalable, sovereign chain that can interoperate with existing Web3 ecosystems

---

### 3. Identity Layer: Decentralized Identifiers (DIDs)

| Feature              | Benefit |
|----------------------|---------|
| 🧑‍💼 Anonymous Mode     | User privacy protection through zero-knowledge ID |
| 🆔 Verified Citizen Mode | Integration with civic identity (opt-in) |
| 🧠 Validator NFT Profiles | Validator history recorded as non-transferable credentials |

---

### 4. Communication Layer: libp2p / Whisper / NKN

| Use Case              | Technology |
|-----------------------|------------|
| Validator-to-Validator | libp2p mesh |
| Secure dispute sharing | Whisper protocol |
| Public civic updates   | NKN decentralized push channels |

---

### 5. Compute Layer: WASM / zk-SNARKs / Rollups

| Use Case                | Technology |
|-------------------------|------------|
| On-chain proof logic     | WebAssembly smart contracts |
| Private validation       | Zero-knowledge proofs (zk-SNARKs) |
| Scaling validator groups | zk-Rollups for batch verification |

---

### 6. Civic App Layer: Web3 Frontend / dApps / SMS Gateways

- 💻 Web3 Dashboard (React + Tailwind + IPFS-hosted UI)  
- 📱 Progressive Web App for mobile reporting  
- 📲 Offline gateway via SMS (for low-connectivity areas)
